# Antarctic Station Integrated Digital Support System (ASIDSS)
## PS 26060 — Digital Platform for Efficient Remote Management of Indian Antarctic Research Stations

**Organization:** MoES · **Department:** NCPOR · **Category:** Software · **Theme:** Disaster Management

---

## 🏔️ Overview

A unified digital platform integrating **infrastructure, energy, logistics, and environmental monitoring** for real-time remote management of India's two Antarctic research stations — **Maitri** (Queen Maud Land) and **Bharati** (Larsemann Hills).

> **⚠️ SIMULATION DISCLAIMER**: All data in this platform is generated by a simulation engine for demonstration purposes. This is not connected to or representative of actual NCPOR station systems.

---

## 🧩 Modules

| # | Module | Description |
|---|---|---|
| 1 | **Energy & Resource Intelligence** | Live telemetry, health index, anomaly detection, What-If simulator, AI mission report |
| 2 | **Personnel Management** | Crew roster, shift management, operational readiness |
| 3 | **Security & Access** | Disaster-relevant zone monitoring (hatches, generator, fuel, lab, comms) |
| 4 | **Logistics** | Resupply schedule, consumables inventory, transport window |
| 5 | **Environmental Monitoring** | Live weather, hazard thresholds, pre-incident advisories |
| 7 | **Polar AI Assistant** | RAG-powered SOP assistant (Groq + offline fallback) |
| 8 | **Emergency & Incident Response** | WS-driven incident management, escalation, muster tracker, evacuation |
| 9 | **3D Digital Twin** | Interactive Three.js station model with live IoT overlay |
| 10 | **IAM / RBAC** | JWT auth, role-based access control, full audit trail |

> Module 6 (Research) intentionally omitted — not specified in PS 26060.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Recharts, D3, Three.js
- **Backend**: Python 3.11, FastAPI, Motor (async MongoDB), Pydantic v2
- **Database**: MongoDB 7.0 (16 collections)
- **Real-time**: Native FastAPI WebSockets (telemetry, incidents, twin)
- **AI**: Groq (Llama 3.1) + TF-IDF RAG offline fallback
- **Auth**: JWT (access + refresh) + RBAC dependency injection
- **Deploy**: Docker Compose (one-command startup)

## 🚀 Quick Start

### Prerequisites
- Docker + Docker Compose (recommended)  
  **OR** Node.js 18+ and Python 3.11+

### Option 1: Docker (Recommended)

```bash
# Clone / navigate to project
cd antarctic-platform

# Copy env template
cp .env.example .env
# Edit .env and add your GROQ_API_KEY (optional — platform works without it)

# Start everything
docker-compose up --build

# In another terminal, seed the database
docker exec antarctic-backend python db/seed.py

# Open http://localhost:3000
```

### Option 2: Local Development

**Backend:**
```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac
pip install -r requirements.txt

# Copy and configure env
cp ../.env.example .env

# Seed database (requires MongoDB running on localhost:27017)
python db/seed.py

# Start backend
uvicorn main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
# Open http://localhost:3000
```
